# Spanish source support withdrawn

The language selector and regional configuration introduced in PR #5 have been removed. The app uses the existing English official source only. The Spanish source was not usable from the tested connection, and native Spanish pagination/playback contracts were never verified.

The earlier [Spanish connection evidence](evidence/5-codex-spanish/README.md) and [design proposal](plans/multiregion.md) are historical records, not supported features or a backlog commitment.

Existing English history and watched flags keep their original preference files. Any Spanish selection or isolated Spanish preferences from earlier builds are ignored and left untouched. No data is deleted or copied between sources. App updates remains available.
